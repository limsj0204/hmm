# 지뢰 던전 (MINE DUNGEON)

지뢰찾기를 로그라이크 던전 탐험으로 바꾼 브라우저 게임입니다.
지뢰 대신 레벨이 있는 마물이 숨어 있고, **숫자는 주변 8칸에 숨은 마물들의 레벨 합**을 알려 줍니다.
약한 마물부터 사냥해 레벨을 올리고, 다섯 층 아래 옥좌에 앉은 심연의 리치를 쓰러뜨리면 승리합니다.

빌드 과정이 없는 정적 웹 페이지라서 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
GitHub Pages에 올려도 그대로 동작합니다.

## 규칙

| | |
|---|---|
| 숫자 | 열린 칸 주변 8칸에 **살아 있는** 마물들의 레벨 합. 마물을 잡으면 숫자도 줄어듭니다. |
| 전투 | 내 레벨 이하의 마물은 피해 없이 처치합니다. 더 강한 마물을 열면 피해를 받고, 살아남으면 처치합니다. |
| 피해 | `⌈(마물 레벨 − 내 레벨) × (마물 레벨 + 1) / 2⌉`. LV1 기준으로 LV2 2, LV3 4, LV4 8, LV5 12. 보스는 두 배. |
| 성장 | 처치하면 경험치(= 마물 레벨)와 골드를 얻습니다. 레벨 k 이하 마물 경험치 총합의 1.1배를 모으면 레벨 k+1이 되므로, 가끔은 한 단계 강한 마물과 피해를 감수하고 싸워야 합니다. 레벨은 층마다 1부터 다시 시작합니다. |
| 정복 | 층의 마물을 모두 처치하면 야영지로 갑니다. 체력을 3 회복하고, 유물 3개 중 하나를 고르고, 상인에게 아이템을 삽니다. |
| 보스 | B5 리치의 옥좌에는 처음부터 모습을 드러낸 LV6 심연의 리치가 있습니다. 쓰러뜨리면 승리합니다. |

### 조작

- **누르기**: 숨은 칸을 엽니다. 열린 숫자 칸을 누르면
  - 숫자가 내 레벨 이하일 때: 주변이 모두 안전하므로 한꺼번에 엽니다.
  - 그보다 클 때: 주변 메모의 합이 숫자와 같으면 나머지 칸을 한꺼번에 엽니다.
- **길게 누르기 / 우클릭 / 메모 모드**: 숨은 칸에 예상 레벨(1–5)이나 `?`를 메모합니다.
- 메모나 정체가 드러난 마물이 내 레벨보다 강하면, 공격 전에 예상 피해를 보여 주고 한 번 더 눌러야 공격합니다.
- 키보드: 방향키 이동, `Space` 열기, `1`–`5` 메모, `?` 모르겠음, `0` 지우기, `M` 모드 전환, `Esc` 메뉴.

### 아이템과 유물

- 아이템: 회복 물약(체력 +5), 수정구슬(칸 하나의 정체 확인), 횃불(가장 약한 마물 3마리 표시), 폭탄(3×3 처치, 보스 제외), 방패(다음 피해 1회 무효).
- 유물 11종: 용사의 검, 강철 투구, 거인의 심장, 흡혈 송곳니, 탐욕의 주머니, 예언자의 눈, 네잎클로버, 영원의 촛불, 불사조 깃털, 현자의 책, 광부의 곡괭이.

진행 상황은 브라우저에 자동 저장되어 새로고침해도 이어 할 수 있습니다.

## 파일 구성

```
index.html        화면 뼈대
style.css         디자인 (어두운 던전, 픽셀 스프라이트, 횃불빛)
js/core.js        게임 규칙. DOM을 쓰지 않아 Node에서도 돈다
js/sprites.js     12×12 픽셀 그림 26종 (문자 그림을 캔버스로 그려 사용)
js/audio.js       WebAudio로 합성하는 효과음 (파일 없음)
js/game.js        화면, 입력, 연출, 저장
tools/            테스트와 밸런스 도구
```

## 개발 도구

```bash
node tools/test-core.js              # 규칙 단위 테스트
node tools/simulate.js 300 --human   # 밸런스 시뮬레이션 (봇이 300판 플레이)
node tools/playtest.js out/          # 브라우저 자동 플레이 (Playwright 필요)
```

`simulate.js`에는 봇이 두 종류 있습니다. 하나는 숫자 제약을 백트래킹으로 풀어 확률까지 계산하는 완전 풀이 봇이고,
`--human`은 "숫자가 내 레벨 이하면 주변은 안전" 같은 단순한 규칙만 쓰는 봇입니다.
첫 설계에서는 단순 규칙 봇조차 피해를 거의 받지 않아 너무 쉬웠습니다. 그래서 레벨업 문턱을 경험치 총합의 1.1배로 올려,
층마다 2–3번은 계산된 피해를 감수하고 싸우도록 바꿨습니다. 지금 봇은 층마다 평균 4 정도의 피해를 받습니다.

`playtest.js`는 실제 화면을 눌러 타이틀부터 승리까지 한 판을 끝까지 진행합니다.
그다음 이어하기, 아이템 사용, 죽음 화면까지 확인하고, 콘솔 오류가 하나라도 나면 실패로 끝납니다.
